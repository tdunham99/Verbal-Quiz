# Boba Milk Tea Recipe Quiz

<ins>Background</ins>

I worked at a Tea Shop back when I was a freshman in college. Being closely located to a high-school, this was a fast paced environment that required me to make orders as efficiently as I could. 

In order to help me memorize the many recipes for milk teas that customers could possibly order. I developed a "pop quiz" written in Java that provides real-time feedback on your answers.
